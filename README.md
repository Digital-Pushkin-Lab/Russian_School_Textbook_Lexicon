# RSTLex: Частотный список лексики российских школьных учебников 1–9 классов

**RSTLex** — это лексическая база данных, построенная на материале корпуса типовых российских школьных учебников для 1–9 классов. База позволяет изучать состав, частотность и распределение лексики школьного образования, а также сопоставлять её с данными общих и детских корпусов русского языка и с внешними лингвистическими ресурсами.

## Данные

Корпус, лежащий в основе базы, включает:

* **58 учебников** для 1–9 классов;
* **3 177 970 словоупотреблений**;
* **44 689 однословных лексем**;
* **10 учебных дисциплин**;
* **9 классов** — с 1-го по 9-й класс.

## Структура 

### 1. Базовые сведения о лексической единице:

* `lemma` — лемма;
* `pos` — часть речи.

### 2. Общие частотные характеристики

Показатели употребительности лексемы во всём корпусе:

* абсолютная частотность;
* относительная частотность в **ipm** — число употреблений на миллион слов;
* документная частота — доля учебников, в которых встречается лексема;
* число учебных дисциплин, в которых лексема зафиксирована хотя бы 1 раз.

Для каждого класса с 1-го по 9-й представлены:

* абсолютная частотность;
* относительная частотность в ipm.

### 3. Распределение по учебным дисциплинам

Для десяти предметных областей представлены абсолютная и относительная частотность:

* география;
* история;
* литература;
* химия;
* математика;
* русский язык;
* обществознание;
* физика;
* окружающий мир;
* биология.

В дисциплину "математика" с 7 класса входят учебники по алгебре и геометрии; в дисциплину "литература" входят учебники по литературному чтению для 1-4 класса; "окружающий мир" оставлен в отдельную категории, т.к. сочетает лексику нескольких дисциплин.

### 4. Распределение по образовательным сферам

Предметные показатели дополнительно агрегированы в четыре укрупнённые образовательные сферы:

* **естественно-научная**;
* **общественно-научная**;
* **гуманитарная**;
* **математическая**.

Для каждой сферы представлены абсолютная и относительная частотность.

### 5. Сопоставление с другими частотными ресурсами

Для оценки специфики школьной лексики в базу включены показатели, позволяющие сопоставить её с лексикой русского языка в других источниках.

В частности, представлены данные **Нового частотного словаря современного русского языка (авторы Ляшевская О.Н., Шаров С.А.)**, включая:

* относительную частотность в ipm;
* индекс `R`;
* индекс `D`.

Также приведена нормализованная частотность в корпусе литературы для детей и подростков **ДетКорпус** (`detcorpus_ipm`), дата обращения к корпусу 08.10.2024

### 6. Лексикографические и лингвистические характеристики

* `slovarnoe_class` — наличие лексемы в списках слованых слов и, в случае наличия - класс (по материалам открытого портала slonum.ru);
* `CEFR` — уровень лексемы согласно лексическим минимумам для взрослых иностранных учащихся;
* `Многозначное` — "да" в случае наличия нескольких синсетов для лексемы в русской версии WordNet;
* `lexical_type` — тип лексемы, автоматически присвоенный на основании распределения лексемы по корпусу (общеупотребительная лексика, гуманитарная сфера, естественно-научная сфера, математическая сфера, социальная сфера)

### 7. Терминология

Для лексем, представленных в списках учебных терминов, указаны: 

* **минимальный класс обучения**, начиная с которого она фиксируется как термин;
* **учебная дисциплина или дисциплины**, с которыми связана её терминологическая употребительность.
* **источник информации о термине**

Для выделения потенциальных терминологических единиц использовались специализированные открытые списки учебных терминов:  

1. 7112 однословных единиц из базы кандидатов в терминологическую лексику по учебникам 5-11 классов [Монахов С. И., Турчаненко В. В., Федюкова Е. А., Чердаков Д. Н. Изучение терминологических подсистем современных школьных учебников на русском языке с помощью модели анализа семантики естественных языков Word2Vec. Journal of Applied Linguistics and Lexicography. 2020, (2): 118–146.] 
2. 4981 единица автоматически извлеченных кандидатов в терминологическеи единицы по учебникам 2–7 классов с платформы RuLex коллектива исследователей КФУ [Платформа Rulex. Списки терминов URL: https://rulex.kpfu.ru/booklist (дата обращения: 10.10.2025)]

**RSTLEX: Corpus-based lexical database of Russian school textbooks, grades 1–9**

The repository contains a lexical database derived from a corpus of typical Russian school textbooks for grades 1–9. The dataset combines frequency and distributional information with linguistic, lexicographic and subject-specific characteristics of lexical units.
